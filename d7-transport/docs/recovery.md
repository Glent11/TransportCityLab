# План восстановления района (Recovery)

## 1. Зависимости
*   Python 3.10+
*   Установленные библиотеки (если требуются, укажите через `pip install ...`)
*   Учебный брокер `broker/local_broker.py`

## 2. Секреты
*   Ключ HMAC (`BUS_KEY`) хранится строго в файле `.env` в корне проекта.
*   Файл `.env` запрещено коммитить в Git (должен быть в `.gitignore`).
*   При развертывании на новой машине ключ передается по защищенному каналу.

## 3. Порядок запуска
1.  Проверить наличие и актуальность файла `.env`.
2.  Запустить брокер: `python broker/local_broker.py` (должен слушать 127.0.0.1:14167).
3.  Запустить консьюмера: `python bus/consumer.py --demo`.
4.  Запустить продюсера для отправки тестового события: `python bus/producer.py demo`.

## 4. Проверка после восстановления
*   Убедиться, что в терминале брокера появились логи о получении сообщения.
*   Убедиться, что консьюмер вывел `"event": "event.consumed"`.
*   Запустить скрипт проверки: `bash scripts/check-bus.sh` (или `python scripts/check-bus.py`). Все тесты должны быть `[OK]`.
